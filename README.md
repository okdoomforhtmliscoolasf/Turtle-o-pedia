# The Turtle Field Guide — Project 009

A responsive, multi-page turtle encyclopedia with an editorial titanite-inspired monochromatic green palette.

## Pages
- `index.html` — overview, habitats, shell introduction and interactive quiz
- `history.html` — fossil history and shell evolution timeline
- `anatomy.html` — shell diagram, carapace/plastron/scutes explainer and breathing
- `species.html` — sea turtle, freshwater turtle and tortoise overview with working filters
- `conservation.html` — current pressures, conservation context and practical actions
- `404.html` — custom GitHub Pages not-found page

## Features
- Responsive desktop and mobile layouts; collapsible mobile navigation
- Clickable TURTLE wordmark with animated underline and scale response
- Golden-ratio-inspired 1.618 aspect ratios, split layouts and spacing rhythm
- Custom scrollbar, reduced-motion support, accessible focus states and skip link
- Favicon, unique page titles and meta descriptions
- Interactive quiz and anatomy selectors with success/error messages
- Species habitat filters
- Image fallbacks, lazy loading and Wikimedia thumbnail-sized image sources
- Footer navigation, linked reading sources and image credits

## Run / publish
Open `index.html` locally, or upload every file to a GitHub Pages repository. Keep the `assets/` folder if you add local images later. Set GitHub Pages to deploy from the repository root so the custom `404.html` is served.
